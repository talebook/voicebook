Voicebook output contract / 2026-08-03

Voicebook 新剧本质量保障方案

在既有 inspect / convert 生产链内部正确提取并整理新剧本：输出可读章节、可朗读正文、语言感知的语义切片和同步 locator，不增加新命令，也不处理已有剧本。

ACTIVE · 已验证 创建日期：2026-08-03 所属模块：book2audio 影响范围：inspect / convert / script / tests 需求来源：Talebook PR 929 真实体验与边界纠正

01 / 原始诉求与确认结论

修生产线，不开修理厂

“百年孤独出现了很多 index_split_000 这种非正常章节。”
“通常一句为一个切片，如果一句太短，就多句联合，大概五十字。”
“芳华的 titlepage 章节，念了一堆 CSS，非正文。”
“已有的剧本就不用管它了，大家只负责产生新的剧本时能正确就行了。”
  • 目标：所有此后由 Voicebook 从 EPUB / TXT 新构建的剧本，在写盘前完成章节、正文、切片和定位的一致性处理。
  • 入口：仍然只有现有 inspect 与 convert；后者复用前者的剧本生产链。
  • 存量：不扫描、不迁移、不重写现存 book.script，不提供 normalize 命令；generate 只读输入剧本并生成音频，永不调用新剧本整理逻辑。

02 / 处理位置

结构问题在提取层解决，切片在首次写盘前完成

read_book过滤结构化非正文；读取目录标题与源 locator
→
角色归因生成 ScriptSegment
→
prepare_new_script确定性切片；仅处理本次内存产物
→
write_voicebook_script剧本与 locator sidecar
→
completed路径、计数与质量报告

read_book 利用 EPUB 标签、spine、nav / NCX 等结构信息排除非正文并确定章节标题；内部 prepare_new_script 接收本次进程刚构建的 VoicebookScript，只在首次写盘前执行确定性切片。inspect 与调用 inspect 的 convert 共享该链路；读取已有脚本的 generate 不进入这条链路。

03 / 新剧本质量规则

四条规则共同决定“能不能朗读”

技术标题不外泄

标题按 EPUB nav / NCX、正文标题节点、首个可靠正文标题的顺序解析。index_split_000、UUID、纯路径文件名不得作为最终标题；仍无法可靠恢复时显示稳定的“未命名章节 N”，不冒充原书章序。

在 HTML 提取层排除非正文

解析 HTML 时跳过 style、script、隐藏节点及其内容，并利用 spine / nav / cover 结构识别技术资源。正文中的 CSS 代码示例仍作为正文保留；提取后没有正文的 titlepage、cover 不生成章节。

句子优先，语言感知

CJK 主导片段按字符计数，目标 50、软下限 28、硬上限 80；非 CJK 片段按单词计数，目标 25、软下限 14、硬上限 40。先按句末标点切句，超长单句再从自然停顿处分开。

locator 与文本同改

每次拆分依据原片段的源字符范围计算新范围、文本哈希、出现序号与 key；解析层先排除非正文再统一编号，并保留稳定 source_key，确保音文高亮仍可回到正确源文本。

确定性切片顺序

  1. 仅使用静态标点和字符类型规则，不调用模型、随机数、时间或外部服务。
  2. 按原始顺序切出句子；超长句在不超过硬上限的候选停顿中选择最接近目标的位置，候选同距时选择更靠前者；没有停顿时按字符边界或英文单词边界硬切。
  3. 只合并同角色、同 locator 基址且源范围连续的相邻短句；贪心选择不超过硬上限且最接近目标的组合，输入顺序决定唯一结果。
  4. 相同输入必须产生逐字节一致的剧本与 locator sidecar。

安全优先级

  1. 宁可保留可疑正文，也不以宽泛关键词误删真实内容。
  2. 只在同角色且源范围连续时合并，避免跨角色改变表演语义。
  3. 无法可靠映射 locator 的片段保留原范围，并在报告中计数，不伪造精确定位。

04 / 输出契约

产物格式兼容，完成事件增加可选报告

book.script 的格式版本保持不变；既有 JSONL inspect completed 事件增加可选、仅含有界计数的 normalization 对象。消费者忽略新字段时行为不变；报告不作为是否处理旧剧本的开关。

报告不包含逐章数组或正文，字段名在实现测试中固定；未来增加字段时旧消费者继续只读取已知计数。

05 / 明确不做

不增加对外操作面

  • 不新增 voicebook-tool normalize 或任何同义子命令。
  • 不读取并重写用户目录里的已有剧本。
  • 不提供旧剧本迁移脚本、批处理任务或兼容性补跑。
  • generate 不修改、重切或重编号输入剧本；单章与整本音频返工都保持输入字节不变。
  • 不把 Talebook 的版本、发布、备份概念引入 Voicebook；Voicebook 仍是无状态生产工具。
  • 不依赖具体 EPUB 厂商文件名来写单书特判。
