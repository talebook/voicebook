# TB-234 生成侧离线评测

从 Voicebook 仓库根目录运行：

```bash
uv sync
uv run python tests/concurrency_20261003/run_evaluation.py
```

需要 ffmpeg / ffprobe。脚本只调用本地模拟引擎生成 PCM WAV，再执行真实规范化、章节合成与 MP3 校验，没有供应商调用。
它使用一本两章书、2 个标题和 8 个正文片段，对照并发 1 与并发 3；模拟慢请求、乱序返回、429、取消、部分失败及新尝试恢复；另有 Edge 共享连接/频率上限、冷却期间取消和等待预算耗尽场景。
Edge 演示的 30ms 间隔仅为加速模拟，生产默认仍为 5 秒；多进程共享 FIFO、重试和计数见 `tests/test_edge_budget.py` 的独立进程验证。

- `results.json`：实际耗时、请求上限、请求数和完整 JSONL 事件。耗时随机器负载变化，不是固定加速承诺。
- `report.html`：可离线展开的逐事件演示，展示工作量和阶段；不是 Talebook 页面回归结果。
- `run_evaluation.py`：可复现脚本，校验上限、计数、章节/正文顺序、持久化快照和完成条件。

针对性单元测试另覆盖重复指纹、退避中取消、超慢探测心跳、失败时工作线程回收、长段分块取消、合成子进程取消、
编码失败不误报完成、刷新读取快照、新尝试计数清零和 force + resume。
